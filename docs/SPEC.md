# Qrop QR — フィールド仕様（QRペイロード形式 CQR2）

QRコードには、「OCR対象フィールドの id・名前・言語・位置・サイズ」を **可変長バイナリ（CQR2）** で記述します。
位置・サイズは **QRコードのサイズを 1 単位とした相対座標** で表します（QRが画面内でどんな大きさ・角度で写っても、フィールドの実位置が一意に決まります）。

> 旧テキスト形式（CQR1 CSV / JSON）は廃止しました。アプリは CQR2 バイナリのみを解釈します。

## 座標系

- 原点 = **QRの左上隅**
- X軸 = QR上辺方向（QRの幅 = `1.0`）
- Y軸 = QR左辺方向（QRの高さ = `1.0`）
- フィールドは `(x, y)` を左上、`(w, h)` を幅・高さとする矩形（すべてQR単位）

```
 (0,0)        x=1
   +-----------+ ── QRコード（1×1単位）
   |    QR     |
   +-----------+
   |
   |   (x,y)
   |    +----------------------+   ← OCR対象フィールド
   |    |  Yamada Taro         |     幅 w, 高さ h（QR単位）
   |    +----------------------+
   v
  y=1
```

実機では、QRの4隅を `Matrix.setPolyToPoly` で正対矩形に写す透視変換を作り、その変換でフィールド矩形を切り出してからOCRします。

> **重要（1単位の定義）**：「QRのサイズ」は、検出器（ML Kit `cornerPoints`）が返す
> **QRシンボル（黒モジュール部分）の四隅**を基準とします。**クワイエットゾーン（周囲の白マージン）は含みません。**
> 帳票やサンプルを作る際は、フィールドのオフセット・サイズを**白枠を除いたシンボルの左上・一辺**に対して
> 計算してください（白枠込みで計算すると、白枠ぶんだけ原点・スケールがズレ、QRから遠いフィールドほど
> 大きく外れます）。`testdata/make_multiform.py` の `gen_qr()` / `cqr2()` が正しい計算例です。

## バイナリレイアウト（little-endian, 固定10Bヘッダ＋末尾name）

| off | size | field | 符号化 |
|---|---|---|---|
| 0 | 1 | `ver` | フォーマット版＝`1`（`rawBytes[0]` を magic 兼用） |
| 1 | 2 | `id` | uint16（DB等の数値キー。不要なら 0） |
| 3 | 1 | `flags` | bit0-1: 言語（`0`=en, `1`=ja）。bit2-7 は予約(0) |
| 4 | 3 | `x,y` | 12bit符号付き **Q8.4** × 2 を3バイトにパック |
| 7 | 3 | `w,h` | 12bit符号付き Q8.4 × 2 を3バイトにパック |
| 10.. | 可変 | `name` | UTF-8（**末尾＝残り全部**。長さフィールド不要） |

- **座標 = 12bit固定小数 Q8.4**（整数8bit＋小数4bit）。実値 = raw/16、**範囲 ±128**、**分解能 1/16≈0.0625**。1.5バイト/値。
- **12bitパック**：2値 (A,B) → `[A>>4, (A&0xF)<<4 | B>>8, B&0xFF]`。復元は逆順（12bitは符号拡張）。
- ヘッダは固定10B。`name` を末尾の可変長にすることで区切り・長さ識別が不要。
- 例: `id=4, en, x=-5.6, y=-0.95, w=6.0, h=0.7, name="issue_date"`
  → 10Bヘッダ＋`issue_date`(10B)=**20バイト**。テキスト相当（37B）の約半分で、QRを低バージョン化できる
  （＝同じ表示サイズでもモジュールが大きく、低解像度・ブレに強い）。
- さらに version 1（21×21, ≤17B）を狙うなら `id` を省く（10文字nameでも 8B+10B=18B…名前を9字以下に）か、
  座標を int8 Q4.4（1B/値・範囲±8）に落とす（精度・範囲とのトレードオフ）。

## デコード（アプリ側）

- ML Kit `Barcode.getRawBytes()`（**バイト透過**）で生バイトを取得して解釈する。
  `getRawValue()`（String）はバイナリだと文字コード解釈で壊れるため使わない。
- `rawBytes[0] != 1` または 12バイト未満は無効として無視。

## 言語コード（flags 下位2bit）

- `1` → ML Kit Japanese（日本語＋ラテン）
- `0`（その他） → ML Kit Latin（英数字）

## 備考

- **1QR=1フィールド**。複数フィールドはQRを複数貼る（アプリはフレーム内の全QRを同時処理）。
- `w, h` は切り出し画像の解像度に影響（実装上 1単位 = 48px、最大2000pxにクランプ）。
- Q8.8 の分解能は 1/256≈0.004、範囲±128。さらに小さくしたい場合は座標を int8 Q4.4（1B/軸,
  分解能1/16・範囲±8）に落とし、`id` を省けば QR version 1（21×21）も狙える（精度・範囲とのトレードオフ）。
