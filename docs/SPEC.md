# Qrop QR — フィールド仕様（QRペイロード形式）

QRコードには、「OCR対象フィールドの名前・言語・位置・サイズ」を記述します。
位置・サイズは **QRコードのサイズを 1 単位とした相対座標** で表します（QRが画面内でどんな大きさ・角度で写っても、フィールドの実位置が一意に決まります）。

## 座標系

- 原点 = **QRの左上隅**
- X軸 = QR上辺方向（QRの幅 = `1.0`）
- Y軸 = QR左辺方向（QRの高さ = `1.0`）
- フィールドは `(x, y)` を左上、`(w, h)` を幅・高さとする矩形（すべてQR単位）

> **重要（1単位の定義）**：ここでいう「QRのサイズ」は、検出器（ML Kit `cornerPoints`）が返す
> **QRシンボル（黒モジュール部分）の四隅**を基準とします。**クワイエットゾーン（周囲の白マージン）は含みません。**
> 帳票やサンプルを作る際は、フィールドのオフセット・サイズを**白枠を除いたシンボルの左上・一辺**に対して
> 計算してください（白枠を含めて計算すると、白枠ぶんだけ原点・スケールがズレ、QRから遠いフィールドほど
> 大きく外れます）。`testdata/make_multiform.py` の `gen_qr()` が正しい計算例です。

```
 (0,0)        x=1
   +-----------+ ── QRコード（1×1単位）
   |    QR     |
   +-----------+
   |
   |   (x,y)
   |    +----------------------+   ← OCR対象フィールド
   |    |  Yamada Taro         |     幅 w, 高さ h（QR単位）
   |    +----------------------+
   v
  y=1
```

実機では、QRの4隅を `Matrix.setPolyToPoly` で正対矩形に写す透視変換を作り、その変換でフィールド矩形を切り出してからOCRします。

## フォーマット1: コンパクト形式 `CQR1`（推奨）

```
CQR1,<name>,<lang>,<x>,<y>,<w>,<h>
```

カンマ区切り。JSONより情報量が小さく、低バージョンQR（黒モジュールが大きく、ブラーに強い）にできます。誤り訂正レベルは **L** 推奨。

| フィールド | 意味 | 例 |
|---|---|---|
| `name` | フィールド名（空なら `field`） | `user_name` |
| `lang` | OCR言語（空なら `en`）。`ja` / `ja_jp` で日本語、それ以外は英語(Latin) | `ja_jp` |
| `x, y` | フィールド左上のオフセット（QR単位） | `1.2, 0` |
| `w, h` | フィールドの幅・高さ（QR単位） | `8, 1` |

例：QRの右側、QR1個ぶん右(`x=1.2`)・同じ高さ(`y=0`)から、幅QR8個・高さQR1個ぶんを `user_name`(日本語)としてOCR：

```
CQR1,user_name,ja_jp,1.2,0,8,1
```

## フォーマット2: JSON 形式

`x,y,w,h` が必須。`name`/`n`、`language`/`l` は省略可（短縮キー可）。

```json
{"name":"user_name","language":"ja_jp","x":1.2,"y":0,"w":8,"h":1}
```

`CQR1,` で始まらないペイロードはJSONとして解釈されます（先頭判定）。

## 言語コード

- `ja`, `ja_jp` → ML Kit Japanese（日本語＋ラテン）
- 上記以外 → ML Kit Latin（英数字）

## 備考

- フィールドは複数定義ではなく**1QR=1フィールド**（現行実装）。複数欲しい場合はQRを複数貼る。
- `w, h` は切り出し画像の解像度に影響（実装上 1単位 = 48px、最大2000px にクランプ）。
